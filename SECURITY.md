# Security

**Breach Budget** uses **fictional** hosts, networks, and attack timelines only. The app does not scan real systems, ingest production logs, or connect to external security APIs.

If you find a vulnerability in this repository (dependency issue, XSS in the demo UI, etc.), please open a [GitHub Security Advisory](https://github.com/FratresMedAI/BreachMark/security/advisories/new) or contact [Kyle Bean on LinkedIn](https://www.linkedin.com/in/kyle-bean-fratresxai/).

Do not commit real credentials, IOCs from live incidents, or customer data to issues or pull requests.
